# Installation

## Stable release

To install back_to_human, run this command in your terminal:

```sh
uv add Back_to_human
```

Or if you prefer to use `pip`:

```sh
pip install Back_to_human
```

## From source

The source files for back_to_human can be downloaded from the [Github repo](https://github.com/kasrsu/back_to_human).

You can either clone the public repository:

```sh
git clone git://github.com/kasrsu/back_to_human
```

Or download the [tarball](https://github.com/kasrsu/back_to_human/tarball/master):

```sh
curl -OJL https://github.com/kasrsu/back_to_human/tarball/master
```

Once you have a copy of the source, you can install it with:

```sh
cd back_to_human
uv pip install .
```
